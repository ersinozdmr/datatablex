# @datatablex/antd

## 0.2.0

### Minor Changes

- e889847: Supports Ant Design 6 and drops Ant Design 5: the `antd` peer range is now `^6.0.0`. The components use the Ant Design 6 names (`Space` `orientation`, `Alert` `title`), and the `"middle"` density renders as the `"medium"` table size, which Ant Design 6 uses in place of `"middle"`; the `Density` values of `@datatablex/react` stay the same. On React 19 the `@ant-design/v5-patch-for-react-19` package is no longer needed.
