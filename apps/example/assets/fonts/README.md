# Fonts

These files are the fonts of the server-side PDF export (`export.pdf.font`). The built-in PDF fonts do not cover Turkish letters, so a real font is required.

- `Roboto-Regular.ttf` and `Roboto-Medium.ttf` are Roboto, Copyright 2011 The Roboto Project Authors (https://github.com/googlefonts/roboto-classic), licensed under the [Apache License 2.0](LICENSE-Apache-2.0.txt). The files are copies taken from the `vfs_fonts.js` of `pdfmake@0.2.20`.
